# Prompt 3 — Cierre (READMEs, verificación y commits)

```text
Revisa todo el proyecto como si fueras mi profesor:
1. Verifica que CADA .erl en src/ y test/ tenga el encabezado de AGENTS.md
   (Programador, Fecha, Descripción). Corrige los que falten.
2. Ejecuta rebar3 compile, rebar3 eunit y rebar3 escriptize && ./_build/default/bin/ejercicios todos.
   Corrige cualquier error o warning.
3. Crea un README.md en la raíz con: título, autora, descripción, requisitos
   (Erlang/OTP + rebar3), cómo compilar/probar/ejecutar, tabla de las 11 prácticas
   (número, módulo, enunciado) y la estructura de carpetas.
4. Crea docs/pNN_nombre.md por práctica con: enunciado, solución, cómo ejecutar,
   notas y una sección "Evidencia" vacía para pegar capturas.
5. Crea un commit por práctica con el formato "feat(pNN): descripción" y un commit
   final "docs: README y evidencias". No hagas push.
Al final muéstrame git log --oneline y un resumen de pendientes.
```
